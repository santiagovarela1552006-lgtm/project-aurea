# Project Áurea

AI-native transaction infrastructure for residential real estate, launching in Madrid before expanding across Europe. This repo holds the founder-draft landing page and a clickable prototype of the investor/buyer cockpit.

**Live site:** https://santiagovarela1552006-lgtm.github.io/project-aurea/
**Cockpit demo:** password-protected, ask the founder for access

## What's in here

- `index.html`, `styles.css`, `script.js`: the landing page
- `privacy.html`, `legal-notice.html`: legal pages
- `cockpit/`: the interactive buyer cockpit prototype (search, AI valuation, mortgage calculator, alerts, checklist, real auction listings)

No build step, no dependencies. Plain HTML, CSS, and JavaScript. Open `index.html` directly in a browser, or serve the folder as-is from any static host.

## Status

Early-stage, pre-incorporation, self-funded. Property listings in the cockpit are fabricated demo inventory; neighborhood price data and the Catastro address lookup use real public sources (cited within the tool). See `privacy.html` and `legal-notice.html` for details.
